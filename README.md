# Android TV Music Recognizer

Приложение для **Android TV и Google TV**, предназначенное для распознавания играющей вокруг музыки с использованием популярных музыкальных сервисов (AudD и ACRCloud) с адаптированным под телевизоры интерфейсом (**10-foot UI** на базе Jetpack Compose for TV).

---

## 🚀 Основные возможности

- **Два движка распознавания музыки**:
  - **AudD API**: Быстрое распознавание треков с интеграцией Spotify и Apple Music.
  - **ACRCloud API**: Профессиональный сервис идентификации аудио с поддержкой метаданных Deezer и Spotify.
- **Интерфейс для телевизоров (10-foot UI)**:
  - Полная поддержка навигации с пульта ДУ (D-pad focus).
  - Динамический фон с размытой обложкой распознанного трека.
  - Анимированные индикаторы захвата звука и процесса распознавания.
- **Источники аудиозахвата**:
  - Встроенный микрофон пульта ДУ (`Remote Mic`).
  - Подключение через USB-микрофон или аудиоинтерфейс (`USB Stick`).
- **Режимы работы**:
  - **Ручной**: Распознавание по нажатию кнопки на пульте.
  - **Непрерывный**: Автоматический запуск распознавания каждые 3 минуты.
- **Экран настроек**:
  - Выбор API и ввод API-ключей (AudD Token, ACRCloud Host/Access Key/Secret).
  - Выбор источника звука и режима распознавания.
  - Сохранение настроек в энергонезависимую память через **Jetpack DataStore Preferences**.

---

## 🛠 Технологический стек

- **Kotlin** & **Coroutines / Flow** (асинхронная обработка аудио и запросов).
- **Jetpack Compose** & **Jetpack Compose for TV** (современный декларативный UI).
- **Material 3** (дизайн и компоненты).
- **Retrofit 2** & **OkHttp 3** (сетевые запросы к API AudD и ACRCloud).
- **Coil** (асинхронная загрузка и кэширование обложек альбомов).
- **DataStore Preferences** (хранение пользовательских настроек).
- **Media3 / AudioRecord** (захват аудиопотока для анализа).

## 📦 Сборка и установка

1. Клонируйте репозиторий или откройте проект в **Android Studio** (рекомендуется версия Ladybug или новее с поддержкой AGP 8.13+ и Kotlin 2.0+).
2. Синхронизируйте проект с Gradle (`File > Sync Project with Gradle Files`).
3. Подключите Android TV устройство или запустите эмулятор Android TV.
4. Выполните сборку и установку приложения:
   ```bash
   ./gradlew :app:assembleDebug
   ```
5. Если всё сложно, просто скачайте apk и установите на свой телевизор.

## ⚙️ Настройка API ключей

Для работы распознавания музыки необходимо получить ключи доступа:
1. Зарегистрируйтесь на [AudD.io](https://audd.io/) для получения токена API.
2. Зарегистрируйтесь на [ACRCloud](https://www.acrcloud.com/) для получения Host, Access Key и Access Secret.
3. В приложении перейдите на **Экран настроек (Settings)** с помощью пульта, введите соответствующие ключи и выберите предпочитаемый сервис распознавания.
